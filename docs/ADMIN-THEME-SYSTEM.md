# SellRight Admin — Theme System

> Implemented in commit 08cfa6f (2026-06-20); fonts self-hosted in ee56172 (2026-06-20). Default theme **Vermillion**; four switchable themes; Schibsted Grotesk, Hanken Grotesk and JetBrains Mono type system.

## What shipped

Replaced the Shopify-green clone with a **runtime-swappable, multi-theme, light/dark token system**.

- **4 themes**, each light + dark. The commit message records WCAG AA contrast checks made with a local script (`.audit/themes/check.cjs`, gitignored and not in the repository; unverified):
  - **Vermillion** (default) — warm paper / warm near-black + coral-vermillion `#CB3D14`/`#FF6242`
  - **Graphite** — cool neutral + iris `#5B5BD6`/`#7C7CF0`
  - **Porcelain** — clean white / true black + cobalt `#0B5FFF`/`#4D8DFF`
  - **Carbon** — warm dark-first + amber `#985C00`/`#F5A623`
- **Switcher** in the top bar (`ThemeMenu`): pick theme + Light/Dark/System. Persists to `localStorage`; a no-flash `<head>` script applies it before first paint.
- **New type system** (replaces Inter everywhere): **Schibsted Grotesk** (display/titles/KPIs) · **Hanken Grotesk** (UI/body, tabular) · **JetBrains Mono** (ids/money/data). All OFL/free, **self-hosted as variable WOFF2** (latin + latin-ext subsets, ~165 KB, loaded on demand) in `packages/admin/src/fonts/` + `packages/admin/src/fonts.css` - no CDN dependency. The `fonts.css` header names `.audit/themes/selfhost-fonts.cjs` as the generator; that script is not in the repository.
- **Lucide icons** kept (modern, consistent 2px stroke — not the problem).
- **Status dots** added to badges (color + shape → color-blind safe), `prefers-reduced-motion` honored.
- **Always-dark shell:** the sidebar uses a dedicated `--shell-*` token set that is **dark in every theme and every mode** (constant, not overridden by `.dark`), so the content area always sits lighter above it - dramatic in light mode (dark rail + light canvas), subtle in dark. Active nav item = theme accent. All shell text/active pairs pass WCAG AA (unverified: see the contrast-script note above).
- **Op-cards fixed:** "To fulfill" / "Low stock" tiles now use `bg-{warning,danger}-soft` tokens (were hardcoded light tints → illegible light-on-light in dark mode).

## Architecture (how it works / how to extend)

- `packages/admin/src/theme-tokens.css` - its first line says it was generated by `.audit/themes/gen-tokens.cjs`, which is gitignored and not in the repository, so edit the file directly. Per-theme CSS variables as **RGB channels** (`--accent: 203 61 20`) on `:root` / `[data-theme="x"]` / `.dark[data-theme="x"]`.
- `src/index.css` `@theme inline` block (Tailwind 4; replaced `tailwind.config.js`) - maps every token to `rgb(var(--x))`, so opacity modifiers (`bg-accent/20`, `ring-accent/35`) work. The **`gray` scale is remapped to a per-theme neutral ramp that inverts in dark** - this is why existing `text-gray-500` / `border-gray-100` / `bg-gray-50` across the admin pages and components re-theme with **zero component edits**. `brand` is repointed to the active accent (so all `bg-brand`/`text-brand`/`bg-brand-light` re-theme too).
- `packages/admin/src/theme.tsx` — `useTheme()` hook + `ThemeMenu` + `applyTheme()` (flips `data-theme` + `.dark` on `<html>`).
- **To add a theme:** add a light block (`[data-theme="x"]`) and a dark block (`.dark[data-theme="x"]`) to `theme-tokens.css`, including the `--shell-*` set, and add a row to `THEMES` in `theme.tsx`.

Files: `packages/admin/src/index.css`, `packages/admin/src/theme-tokens.css`, `packages/admin/src/theme.tsx`, `packages/admin/src/components/ui.tsx` (badges/alerts/deltas/title), `packages/admin/src/components/Layout.tsx` (switcher), `packages/admin/src/pages/Dashboard.tsx` (op-card tints) and `packages/admin/index.html` (no-flash init).

## Known follow-ups (small, not blocking)

1. **3 hardcoded semantic tints remain** (`bg-red-50` in `ErrorBoundary.tsx`; `bg-amber-50` in `Discounts.tsx` and `AgentAccess.tsx`) and will look slightly washed in dark - swap to `bg-{danger,warning,success}-soft`.
2. **Stray `text-white` on accent** (57 uses of `text-white` in `packages/admin/src`, for example on spinners inside `btn-primary` buttons) - fine in the light themes (white on-accent) but should be `text-accent-on`, because the dark modes set a dark `--on-accent`.
3. ✅ ~~Self-host the fonts~~ — done (variable WOFF2, latin + latin-ext, in `packages/admin/src/fonts/`).
4. Optional: a density toggle; settings-page mirror of the theme picker.
