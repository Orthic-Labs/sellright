## (b) Per-competitor sentences (fetched 2026-10-15)

Quotes are from the fetch tool's extraction of each page, not read directly in a browser.

- **Vendure.** Licence/pricing: "Vendure Core is open source under GPLv3, with a plugin exception"; "Your plan price stays the same whether you host Vendure yourself or run it on Vendure Cloud" (https://vendure.io/pricing). Multi-store: "This allows you to run multiple shops from a single Vendure server" (https://docs.vendure.io/guides/core-concepts/channels/); the page says nothing about database isolation. API: "A single extensible core serves any frontend through a GraphQL API" (https://github.com/vendure-ecommerce/vendure). Order editing: "an order can be modified after checkout is completed" per a search-result summary of https://www.vendure.io/docs/user-guide/orders/. Requirements: "512MB per process would be a practical minimum" (https://docs.vendure.io/guides/deployment/server-resource-requirements/).
- **Medusa.** "The core is licensed under the MIT License" (https://github.com/medusajs/medusa/blob/develop/LICENSE). "Medusa only supports PostgreSQL as the underlying database" (https://docs.medusajs.com/learn/introduction/architecture). "A Medusa application is made up of a Node.js server and a Vite admin dashboard" (https://docs.medusajs.com/learn/installation). "This API reference includes Medusa v2's Admin APIs, which are REST APIs" (https://docs.medusajs.com/api/admin). "Make changes to an order to edit, return, or exchange its items" (https://docs.medusajs.com/resources/commerce-modules/order). Sales channel page does not confirm separate storefronts or DB isolation (https://docs.medusajs.com/resources/commerce-modules/sales-channel).
- **Saleor.** "BSD-3-Clause license" and "GraphQL only" (https://github.com/saleor/saleor). "Sales channels allow you to model your data across different regions, brands, and business models" (https://docs.saleor.io/developer/channels/overview); no database isolation statement. Pricing page: Select $1,599/mo, Volume $3,999/mo, plus a "Non-Commercial Use Only" banner that the page does not explain (https://saleor.io/pricing). Payments: guides for Adyen and Stripe (https://docs.saleor.io/developer/payments).
- **Sylius.** "Sylius is completely free and released under the MIT License"; "Powerful REST API"; Sylius Plus adds "multi-store management, a B2B suite, and multi-source inventory" (https://github.com/Sylius/Sylius). Requirements (PHP 8.2+, MySQL 8.0+/MariaDB 10.4.10+/PostgreSQL 13.9+) come from a search-result snippet of https://docs.sylius.com/the-book/installation/system-requirements; direct fetch redirected to a sign-in gate and was not followed.
- **Spree.** Repository text: React admin, Next.js storefront, "a REST API ... and an OpenAPI 3.0 spec", Stripe, Adyen and PayPal included; "Fully isolated multi-tenant stores are listed as Enterprise Edition only" (https://github.com/spree/spree). Enterprise page: "Community Edition uses BSD-3-Clause for backend code and MIT for frontend code"; Enterprise is "Custom Pricing" (https://spreecommerce.org/enterprise/). Isolation, vendor blog: "Spree Commerce delivers row-level tenancy on one codebase and one database across every tenant" and "Spree Commerce enforces tenant_id filtering and Row Level Security policies", but the same page also says "Spree Commerce provisions each tenant its own database under the complete isolation model" (https://spreecommerce.org/multi-tenant-ecommerce-architecture-choosing-between-row-level-and-complete-isolation/). Docs: "The Store is the top-level tenant in Spree"; full isolation "is supported by the Spree Multi Tenant extension, which is a separate gem" (https://spreecommerce.org/docs/developer/core-concepts/stores).
- **Solidus.** "BSD-3-Clause license"; `solidus_backend` provides admin, `solidus_api` provides a RESTful API; databases PostgreSQL, MySQL, MariaDB, SQLite (https://github.com/solidusio/solidus). Home page lists a "powerful admin dashboard" and a starter theme (https://solidus.io/).
- **Bagisto.** "will always remain free under the MIT License"; Docker images with MySQL 8.0, MariaDB 10.11 or PostgreSQL 16 (https://github.com/bagisto/bagisto). "Build & Scale Your Online Store from $25/Month" and multi-tenant SaaS "manage multiple storefronts" (https://bagisto.com/en/). Whether the SaaS multi-tenant product is part of the MIT core is not stated.
- **Magento / Adobe Commerce.** "A single installation can have multiple websites, and each website can have multiple stores and store views" (https://experienceleague.adobe.com/en/docs/commerce-admin/start/setup/websites-stores-views). Licence "OSL-3.0 and 2 other licenses found" (https://github.com/magento/magento2). Adobe Commerce 2.4.9: PHP 8.5, MariaDB 12.3 (MySQL 8.4 listed), OpenSearch 3 (https://experienceleague.adobe.com/en/docs/commerce-operations/installation-guide/system-requirements). Payments: Braintree "bundled vendor-developed extension", PayPal variants, offline methods (https://experienceleague.adobe.com/en/docs/commerce-admin/stores-sales/payments/payments).
- **WooCommerce.** "the free, open-source ecommerce platform for WordPress", 0% revenue share (https://woocommerce.com/pricing/). Requirements: "PHP version 8.3 or greater", "MySQL version 8.0 or greater, or MariaDB version 10.6 or greater", "WordPress memory limit of 256 MB or greater" (https://woocommerce.com/document/server-requirements/). "WooCommerce (WC) 2.6+ is fully integrated with the WordPress REST API" (https://developer.woocommerce.com/docs/apis/rest-api/).
- **Shopify.** "Shopify includes secure commerce hosting with your Shopify plan" (https://www.shopify.com/pricing). "The REST Admin API is a legacy API as of October 1, 2024" (https://shopify.dev/docs/api/admin-rest). Orders can be edited "after they're placed to make adjustments before fulfillment" (https://help.shopify.com/en/manual/fulfillment/managing-orders/editing-orders). "If you have multiple stores, then you can create an organization" (https://help.shopify.com/en/manual/organization-settings/multistore).
- **PrestaShop.** Classic offer: "Free download"; hosted EUR 24/month annual, EUR 29/month (https://www.prestashop.com/en/download). "We recommend setting the memory allocation per script (memory_limit) to a minimum of 512M" and MySQL 5.7 / MariaDB 10.2 minimum (https://devdocs.prestashop-project.org/9/basics/installation/system-requirements/). "Turning your single-shop PrestaShop installation into a multi-shop one is very simple" (https://docs.prestashop-project.org/v.8-documentation/user-guide/configuring-shop/advanced-parameters/multistore). Webservice: "a CRUD API" (https://devdocs.prestashop-project.org/9/webservice/).
- **Shopware.** "completely free and released under the MIT License" (https://github.com/shopware/shopware). "so one Shopware instance can serve multiple "stores" without duplicating data" (https://developer.shopware.com/docs/concepts/commerce/catalog/sales-channels.html). Fair Usage Policy: shops over EUR 1M GMV in 365 days need a paid plan to keep Account and Store access; "You can keep using the software independently" (https://www.shopware.com/en/pricing/). "8 GB minimum, 16 GB recommended (especially for Docker)" (https://developer.shopware.com/docs/guides/installation/system-requirements.html).
